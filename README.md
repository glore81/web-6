# Assignment 6: jQuery & DOM Manipulation
Temkeshev Aldiyar SE-2527

A multi-page web development project showcasing core jQuery capabilities, interactive DOM manipulation, effects, and custom UI animations styled with Bootstrap 5.

---

## Overview

The repository consists of 12 tasks (`task0.html` through `task11.html`), each focusing on specific jQuery API methods and practical web UI interaction patterns. All pages share a consistent responsive layout with a top navigation bar.

---

## Tasks Summary

| Task | Title | Key jQuery Methods / Concepts | Description |
| :--- | :--- | :--- | :--- |
| **Task 0** | Setup & Integration | `$(document).ready()` |
| **Task 1** | Selectors & Basic Actions | `$("#id")`, `$(".class")`, `.text()`, `.html()` |
| **Task 2** | Visibility Methods | `.hide()`, `.show()`, `.toggle()` |
| **Task 3** | Fade Methods | `.fadeIn()`, `.fadeOut()`, `.fadeToggle()` |
| **Task 4** | Slide Methods | `.slideUp()`, `.slideDown()`, `.slideToggle()` |
| **Task 5** | Add & Remove Elements | `.append()`, `.prepend()`, `.remove()`, `:last-child` |
| **Task 6** | Modifying Attributes | `.attr()`, `.text()` |
| **Task 7** | Form Interaction | `.val()`, `.text()`, `.on("input", ...)` |
| **Task 8** | Basic Animation | `.animate()` |
| **Task 9** | Sequential Animations | `.animate()` method chaining, `.stop(true)` |
| **Task 10** | Combined Animation | `.animate()` with multiple simultaneous properties |
| **Task 11** | Interactive Project (Bouncing Ball) | `.animate()`, linear easing, coordinate physics |
